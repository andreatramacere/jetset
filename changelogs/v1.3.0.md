# JetSeT v1.3.0

## Added
- Apple ARM binaries (pip and conda, Python 3.11).
- C-threaded computation in `JetBase` and derived classes, including runtime thread control.
- Leptonic synchrotron polarization support.
- New custom-model examples, including galactic expanding shell and two-zone composite jet.
- Minimizer improvements:
  - Correlation heat map convenience method.
  - `simplex` support on top of `migrad` in `minuit`.
- MCMC usability improvements:
  - Dedicated methods for label and bounds setup.
  - Option to plot MCMC best-fit model and residuals.
  - Plot-label customization support.
- New EBL models:
  - Franceschini et al. (2008)
  - Finke et al. (2010)
  - Dominguez et al. (2011)
  - Dominguez and Saldana-Lopez (2023)
- EC improvements for anisotropic external fields at large angles.
- New convenience methods:
  - `JetBase.make_conical_jet`
  - `JetBase.set_EC_dependencies`

## Changed
- Improved dependent-parameter handling with astropy units.
- Improved serialization robustness across future astropy/numba interface changes.
- Improved light-curve merge functionality.

## Fixed
- Typo fix in `EC_components_list` keyword for `ObsConstrain.constrain_SSC_EC_model`.
