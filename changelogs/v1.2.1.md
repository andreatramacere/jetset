# JetSeT v1.2.1

## Added
- Depending parameters: model parameters can be linked via functional dependencies.
- Temporal evolution: Python interface for self-consistent evolution of leptonic emitters under acceleration and cooling.
- Hadronic pp emission: Python interface support added.
- Expanded SSC/EC theoretical-background documentation.
- Emitters-distribution class improvements.
- EBL absorption parameter-linking updates.
- Plugin additions:
  - Sherpa plugin and Sherpa minimizer plugin.
  - Gammapy plugin.
