# JetSeT v1.4.0

## Breaking changes
- `McmcSampler` no longer uses `labels` / `use_labels_dict` to choose sampled parameters.
- Starting in v1.4.0, all `free` parameters are sampled.
- To control sampled parameters, use `free` / `freeze`.

## Added
- `UltraNest` backend support, including OpenMPI example workflow, including examples for model fitting
- Additional `emcee` example in model-fitting workflow.
- Leptonic-equilibrium support using injected emitters distributions, including examples for SSC and EC model fitting 
- Analytical radio component `RadioSpectrum` for composite jet + radio models.
- EC support for Corona.
- Pair-production absorption support for external fields (DT, BLR, Corona), including examples for EC model fitting 
- Source installation helper via `./install.sh`.

## Changed
- `McmcSampler.plot_model` now defaults to plotting the MCMC best-fit model.
- `McmcSampler.set_bounds` supports per-parameter usage.
- `emcee` burn-in can be retuned via autocorrelation time (`tune_burnin`).
- Internal absorption can be enabled in EC fitting workflows.
- Optional `use_R_H_profile_extrapolation` support for internal absorption.
- Data handling updates:
  - Upper limits are handled in SED rebinning.
  - Added `nu` min/max controls in rebinning.
  - ASI SSDC sedbuilder integration.
- C codebase refactored with hierarchical blob sub-structures.
- `./install.sh` behavior improved for conda/mamba/micromamba and pip environments.

## Fixed
- Minor bug fixes.
- Typos in variable names.
- Serialization bug fix for depending parameters.

## Notes
- For Bayesian-fitting caveats and examples, refer to the user-guide sections linked from the official JetSeT documentation.
